# 门卡时刻 · 版本发布

本仓库用于发布门卡时刻 APK 和应用内更新描述。

## 当前版本

0.2.1（versionCode 3）。支持本地刷卡提示记录、每日首末记录工时、中国工作日缺卡提醒和手动检查更新。

- [下载安装包](apk/DoorLog-0.2.1.apk)
- [查看更新描述](update.json)

从旧版直接覆盖安装，保留原有记录；请勿先卸载。

## App 更新地址

在 App 的“设置 → 版本更新”中填入：

https://raw.githubusercontent.com/St0Bjahr/doorlog-releases/main/update.json

0.2.1 已将此地址作为默认更新来源。点击检查更新后，仅当 versionCode 比本机更高时提示下载，由 Android 安装程序确认覆盖安装。

## 功能

- 每日最晚记录减最早记录，可配置扣休时间；只有一条时显示记录不足。
- 默认在中国工作日 08:50、09:10、17:50、18:10 检查对应时段缺卡情况。
- 内置 2026 放假／调休日历；新年份需补充对应日历。
- 刷卡与工时保存在本机；只有主动检查／下载更新时访问发布文件。

## 维护下一版本

1. 沿用原签名，并递增 APK versionCode。
2. 把已签名 APK 上传到 `apk/` 目录，采用含版本号的文件名。
3. 修改根目录 update.json：versionCode、versionName、apkUrl、sha256 和 notes。
4. 校验远程 APK 与 JSON 中 SHA-256 一致后再发布更新描述。

此仓库仅发布安装包、版本描述和说明。签名密钥保留在维护者的私人构建环境中。

GitHub 原始文件下载的可达性取决于手机所用网络。
